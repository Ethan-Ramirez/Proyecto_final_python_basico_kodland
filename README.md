# Boto, el bot que te enseña de cambio climático (Bot para Discord)
Este proyecto consiste en un bot para meter en cualquier canal de Discord para consientizar a los usuarios sobre este gran problema que esta destruyendo al mundo.

# Funcionalidades:
- /learn: Explica en un texto simple en que consiste el cambio climatico
- /ignorant: Explica desde lo más básico para alguien totalmente ignorante
- /random: Dice un dato al azar sobre el cambio climático
- /climate (city): Te dice el clima y termperatura de tu ciudad en tiempo real
- /bcommands: muestra todos los comandos del bot
- /commands: muestra los comandos del chat (los que no incluyen al bot)
- /allcommands: muestra todos los comandos
- /help: explica de que se trata el chat

# Tecnología
- Python
- Discord
- APIs
